`.env`에는 보통 API 키 같은 비밀값을 넣습니다. 그래서 파일을 만들면서 GitHub에 올라가지 않도록 `.gitignore`에도 함께 추가하겠습니다.

프로젝트 폴더에 [.env](.env) 파일을 만들었습니다. [.gitignore](.gitignore)에도 `.env`를 추가해서 GitHub에 올라가지 않게 해 두었고, Git이 이 파일을 무시하는 것까지 확인했습니다.

## 사용 방법

**1. 값 넣기**

[.env](.env)를 열고 아래처럼 `이름=값` 형식으로 한 줄씩 적습니다. 등호(`=`) 앞뒤에 공백을 넣지 마세요.

```
ANTHROPIC_API_KEY=sk-ant-여기에실제키
```

어떤 이름을 써야 하는지는 `.env`를 만들라고 안내한 곳(강의 자료나 문서)에 나와 있을 거예요. 그대로 따라 적으시면 됩니다.

**2. 코드에서 불러오기**

먼저 `python-dotenv` 패키지를 추가합니다.

```powershell
uv add python-dotenv
```

코드에서는 이렇게 읽어옵니다.

```python
import os
from dotenv import load_dotenv

load_dotenv()                            # .env 파일 내용을 불러옴
api_key = os.getenv("ANTHROPIC_API_KEY")
```

## 직접 만드는 방법 (참고용)

다음에 다른 프로젝트에서 직접 만들 때는 둘 중 하나를 쓰시면 됩니다.

- **VS Code:** 왼쪽 탐색기에서 새 파일 아이콘을 누르고 이름을 `.env`로 입력
- **터미널:** `New-Item .env`

`.env` 파일은 한 번 GitHub에 올라가면 지워도 기록에 남습니다. 새 프로젝트를 시작할 때는 `.gitignore`에 `.env`가 들어 있는지 꼭 먼저 확인하세요.

그리고 프로젝트 안에 `aiwins/`라는 폴더가 새로 생겨 있습니다. 직접 만드신 게 아니라면 알려 주세요. 무슨 폴더인지 확인해 보겠습니다.

네, `.env`에 넣으면 됩니다. `sk-proj-`로 시작하는 키는 OpenAI 키라서 `OPENAI_API_KEY`라는 이름으로 추가하겠습니다.
